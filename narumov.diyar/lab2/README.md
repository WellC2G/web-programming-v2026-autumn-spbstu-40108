# Лабораторная работа 2

## Задание

Вариант 37. Реализовать функцию `formatPhoneNumber(phoneStr)` для форматирования
строки телефона под шаблон `"+7 (XXX) XXX-XX-XX"`.

## Реализация

Функция `formatPhoneNumber` объявлена в `solution.js` и экспортируется
именованным export. Сначала проверяются входные данные: если передана не строка,
выбрасывается `TypeError`. Затем цикл `for ... of` перебирает символы строки и
собирает в строку `digits` только цифры, поэтому пробелы, скобки и дефисы во
входных данных не мешают. Если цифр оказалось не ровно десять, выбрасывается
`Error` с описанием проблемы. Для корректного номера методом `slice` берутся
четыре части: код из трех цифр, следующие три цифры и две пары последних цифр.
Результат собирается шаблонной строкой
`+7 (${code}) ${firstPart}-${secondPart}-${thirdPart}`.

## Запуск

Решение является ES module. Импортируйте именованный export `formatPhoneNumber`
из `solution.js` и вызовите его со строкой телефона:

```js
import {formatPhoneNumber} from './solution.js';

console.log(formatPhoneNumber('9991234567'));
// Вывод: +7 (999) 123-45-67
```
